# Documentation authoring

The canonical policy is the [HomeLab documentation standard](documentation-standard.md).
It governs public property records, contextual links, examples, lifecycle claims
and evidence. This page preserves the former entry point; it is not a second policy.

Start with the [contributor workflow](README.md), choose a
[reference](../templates/configuration-reference.md),
[task](../templates/task-guide.md) or [tutorial](../templates/tutorial.md)
template, and consult [documentation assurance](documentation-assurance.md) for
the checked scope and [testing](testing.md) for actual commands.
