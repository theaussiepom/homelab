# Security

Report suspected vulnerabilities through this repository's GitHub **Security → Report a vulnerability** form. Do not put credentials, private deployment details, or exploit material affecting a live household into a public issue.

This repository contains public source and synthetic examples. Deployments must supply credentials and identifying values privately. Public CI never reads production inventory, connects to household hosts, or deploys changes.

Secret scanning and CI checks are safeguards, not proof that a file is safe to publish. Review the exact proposed content, history, metadata, and any binary assets before a first push. A public branch is already published even before its pull request is merged.
